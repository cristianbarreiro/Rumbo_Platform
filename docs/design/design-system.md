# Sistema de diseño

Objetivo: identidad visual coherente en Web y Android, adaptada a controles nativos.

Pendiente extraer y comparar colores, tipografía, espaciado, radios, iconos y estados desde ambas implementaciones. No hay tokens compartidos aprobados todavía. Los futuros tokens se guardarán en design/tokens con su origen, versión y mapeo a CSS y Compose.
