# Requisitos compartidos propuestos

- Mantener vocabulario y comportamiento coherentes para líneas, paradas, vehículos y llegadas.
- Identificar claramente datos simulados, errores, ausencia de datos y tiempos de actualización.
- Mantener mapa y navegación utilizables en cada plataforma, con accesibilidad y adaptación a su tamaño de pantalla.
- Comparar escenarios equivalentes entre Web y Android antes de declarar paridad.

Estos criterios orientan el trabajo posterior; no afirman que todas las funciones estén implementadas.
